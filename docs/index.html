Git, but friendly.

SillyGit is a desktop Git client with a clear commit graph, staging down to single lines, a real three-way merge tool, and Claude built in. The name is silly; the Git underneath is real.

Why SillyGit

It's real Git

Every action runs the git on your PATH with your own config, hooks and credentials. The activity log shows exactly what ran.

Conflicts stop being scary

A three-way merge tool with per-chunk and per-line choices, bulk resolution with undo, and AI suggestions when you're stuck.

One checkout, many branches

Lanes keep changes for different branches in the same working tree, and commit each to its own branch.

Free and open

MIT licensed. No account, no telemetry, no paywalled features. Built in the open on GitHub.

Merge conflicts

A merge tool you'll actually use

See both sides and the result together. Take ours, theirs or both for each chunk or single line, edit the output by hand, and resolve many files at once with undo. Conflicts from merges, rebases, cherry-picks and stash pops all land in the same place.

Lanes

Work on several branches at once

Fixing a bug in the middle of a feature? Turn on lanes, move each file to the lane it belongs to, and commit every lane to its own branch, all without stashing or switching.

Claude

Claude, right next to your graph

Chat with Claude Code inside SillyGit. Every edit and command arrives as a card you approve, with the diff right there. AI commit messages, reviews and help splitting a big change are a click away.

Staging

Commit exactly what you mean

Stage, unstage or discard whole files, single hunks or individual lines. Fix up an earlier commit, or absorb staged hunks into the unpushed commits they belong to.

Help

Help that's always one key away

A short walkthrough on first launch and over 50 help articles, each with a worked example. Press F1 or ? anywhere in the app.

And plenty more

  • Interactive rebase by drag and drop
  • Pull requests: review, create and check out
  • Accounts for GitHub, GitLab, Bitbucket, Gitea and Azure DevOps
  • Start work on GitHub issues, Jira tickets and Azure Boards items
  • Guided bisect, git-flow and stacked branches
  • Blame, file history and image diffs
  • Built-in editor, terminal and command palette
  • Multi-repo tabs that come back where you left them
  • Git LFS, tags, worktrees and submodules
  • Undo and redo for everyday operations
  • Search history by message, author, path or content
  • Light, dark or system theme
